# Counterpick — 5 UI directions

Интерактивный адаптивный HTML-showcase мобильного помощника по выбору героев в Dota 2.

## Дизайн-направления

- Aegis Aperture
- Captain’s Ledger
- Twin Ancients
- War Table
- Match Signal

Каждое направление поддерживает светлую и тёмную темы, мобильный режим и desktop preview.

## Сценарии

- ручной драфт и загрузка фото;
- каталог героев и проверка распознавания;
- Match Found loader с десятью подтверждениями;
- три рекомендации с индексом соответствия, преимуществами и рисками;
- история, профиль, вход, регистрация и Pro;
- загрузка, ошибка, пустые данные, нет фото, лимит, офлайн и удаление с Lottie.

Все аккаунты, тарифы, загрузки и платежи работают в демонстрационном режиме.

## Запуск

```bash
npm install
npm run dev
npm test
```

Основной интерфейс находится в `app/page.tsx`, дизайн-системы и адаптивность — в `app/globals.css`.
