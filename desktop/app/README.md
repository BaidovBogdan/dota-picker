# Counterpick Desktop

Desktop-компаньон Dota Picker на Electron, React и TypeScript. В режиме Vision приложение использует Game State Integration для определения фазы драфта, команды и выбранного локальным игроком героя. Исходные ID/имя выбранного героя остаются в памяти, не отправляются и не сохраняются; вместе с изменившимся кадром в API уходят только вычисленная сторона визуальной группы и метка источника. Приложение локально снимает только окно Dota 2 и передаёт изменившиеся кадры в API для распознавания и расчёта. Кадры обрабатываются в памяти и не сохраняются. Отдельный режим Overwolf Live получает структурированные события через локальный companion.

## Запуск

Требования: Node.js 22.22 или новее, npm 10 или новее.

```powershell
npm install
npm run dev
```

Production-проверка:

```powershell
npm run build
npm run package
```

`npm run package` создаёт распакованное приложение, а `npm run dist:win` — Windows NSIS-установщик, update metadata и blockmap. `npm run verify:packaging` проверяет исходный packaging-контракт, а `npm run verify:dist` — готовые Windows-артефакты. Текущая desktop-версия — `0.1.11`; в Electron-пакет включаются только локали `en-US` и `ru`.

## API

По умолчанию используется Render:

```text
https://dota-picker-api.onrender.com/v1
```

Для локального backend скопируйте `.env.example` в `.env.local` и задайте:

```text
MAIN_VITE_API_URL=http://127.0.0.1:3000/v1
```

HTTP разрешён только для localhost. Для удалённого API требуется HTTPS.

## Автоматический помощник

При первом включении приложение запрашивает согласие на захват окна Dota 2. Затем оно:

1. Находит Steam и устанавливает `gamestate_integration_counterpick.cfg`.
2. Поднимает локальный GSI receiver только на `127.0.0.1:32123`.
3. Ждёт `HERO_SELECTION` или `STRATEGY_TIME`.
4. Захватывает окно Dota 2 через системный `desktopCapturer`.
5. Пропускает неизменившиеся кадры, применяет минутный rate limit и отдельный ограниченный бюджет кадров на live-анализ.
6. После первого результата продолжает дешёвое наблюдение и обновляет тот же анализ только при фактическом изменении набора пиков; одинаковые кадры не расходуют лимит ревизий и не создают новый quota charge.

Для надёжного захвата рекомендуется режим Dota 2 «Окно без рамки». Приложение не читает память процесса, не внедряется в игру и не захватывает весь рабочий стол.

Перед запуском Dota 2 добавьте в Steam → Dota 2 → Свойства → Параметры запуска:

```text
-gamestateintegration
```

Если система зарегистрировала `PageUp`, во время драфта эта клавиша показывает и скрывает overlay. Если клавиша недоступна, в меню трея появится пометка `PageUp недоступен`; там же остаётся команда показа и скрытия overlay. В overlay можно выбрать позицию 1–5 и вручную проверить новые пики кнопкой обновления. После смены позиции текущий драфт пересчитывается для выбранной роли. Draft Vision автоматически сопоставляет стороны, когда выбранный локальным игроком герой однозначно найден в одной визуальной группе. Пока такого сигнала нет, overlay один раз предлагает указать, где находится команда игрока; выбор действует только до конца текущего драфта и не сохраняется в настройках.

## Overwolf Live и Windows-установщик

Overwolf Live извлекает из GEP и передаёт в Counterpick только ID героев, стороны, позицию и состояние драфта через аутентифицированный WebSocket на `127.0.0.1`. Остальные поля исходных GEP-событий отбрасываются и не отправляются или сохраняются; токены Counterpick, скриншоты и браузерные данные companion не получает.

При новой интерактивной установке Counterpick NSIS отдельно проверяет наличие базовой платформы Overwolf. Если её нет, пользователь видит необязательный, изначально выключенный checkbox. Только после явного выбора установщик:

1. скачивает официальный bootstrapper с HTTPS-адреса, на который ведёт Overwolf Appstore;
2. требует валидную Windows Authenticode-подпись с разрешённым именем издателя Overwolf;
3. запускает официальный установщик интерактивно, без silent-флагов и без принятия условий от имени пользователя.

При ошибке загрузки, подписи или запуска бинарник не выполняется; вместо этого можно открыть официальный Overwolf Appstore в браузере. Silent-установка Counterpick и обновления не запускают этот сторонний flow. Установка базовой платформы не означает установку Counterpick Live: companion пока не опубликован в Overwolf Appstore и до одобрения должен загружаться только вручную в developer-whitelisted окружении.

## Безопасность

- Renderer работает без Node.js, с `contextIsolation`, sandbox и узким typed bridge.
- IPC принимает сообщения только от main frame текущего окна и валидирует входные данные через Zod.
- Access token хранится только в памяти main process.
- Refresh token шифруется средствами операционной системы через Electron `safeStorage`.
- Внешняя навигация, popup-окна и permissions renderer отключены.
- Разрешены только проверенные HTTPS- и mailto-ссылки.
- Кадры Vision обрабатываются в памяти и не сохраняются как вложения анализа.
- Необязательный Overwolf bootstrapper запускается только после отдельного согласия и успешной проверки официального HTTPS-источника и Authenticode-подписи.

